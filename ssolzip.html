SSolZip

파일을 압축하고 압축파일을 해제할 수 있는 Windows용 압축 프로그램

다운로드 안내 사용 방법

여러 파일을 묶거나 압축파일을 열어야 하나요?

  • Windows 환경에서 사용하는 압축 프로그램
  • 개인용뿐 아니라 회사 등 상업적 용도로도 사용 가능

여러 파일을 하나로 묶어 보관하거나 전달할 때 사용할 수 있습니다. 받은 압축파일을 해제할 때도 SSolZip을 이용해 보세요.

사용 환경 및 이용 안내

SSolZip은 Windows용 프로그램이며 상업적 용도로 사용할 수 있습니다. 지원하는 Windows 버전과 파일 형식 등 세부 사항은 배포 파일에 포함된 안내를 확인해 주세요.

사용 방법

  1. SSolZip을 Windows PC에 설치하거나 실행합니다
  2. 압축할 파일 또는 해제할 압축파일을 선택합니다
  3. 저장 위치를 확인한 뒤 필요한 작업을 진행합니다
