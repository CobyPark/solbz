Codex 01. 어디서 작업할까: 앱·CLI·IDE와 실행 환경 고르기

솔루션 비제트 · OpenAI 공식 문서 기반 가이드 · 2026.10.19

Codex를 처음 켜면 앱, CLI, IDE 중 무엇을 쓸지부터 고민하게 됩니다. 여기서 한 가지 더 정해야 합니다. 파일을 내 컴퓨터에서 고칠지, 별도 worktree나 클라우드에서 고칠지입니다. 화면과 실행 장소를 따로 놓고 보면 선택이 한결 쉬워집니다.

앱과 CLI는 화면, Local과 Cloud는 작업 장소

앱에서는 채팅과 변경 검토 화면을 함께 사용할 수 있고, CLI는 터미널 중심 작업에, IDE 확장은 편집 중인 파일과 가까운 작업에 적합합니다. 클라이언트별 지원 기능은 해당 설치 안내에서 확인할 수 있습니다.

Local은 현재 컴퓨터의 프로젝트에서 작업하고 Worktree는 로컬 Git 변경을 별도 체크아웃에 분리합니다. Cloud는 준비된 원격 환경을 사용합니다. 앱을 쓴다는 사실만으로 실행 위치가 로컬이나 클라우드로 결정되는 것은 아닙니다.

수정할 저장소는 어디에 있나

수정할 저장소의 폴더와 브랜치, 아직 커밋하지 않은 변경을 먼저 확인합니다. Cloud 작업에 내 PC의 파일·로그인·실행 중 서버가 자동으로 전달되지는 않습니다. 필요한 저장소와 도구가 실제 환경에서 접근 가능한지 살펴보세요.

처음에는 폴더 설명부터

프로젝트를 처음 연결했다면 구조와 실행 방법을 설명해 달라고 요청해 맥락을 확인할 수 있습니다. 이어서 파일 한두 개의 작은 변경으로 편집·검증 흐름을 익힙니다. 변경된 파일과 실행한 검사는 요약과 함께 살펴보세요.

첫 요청은 파일 구조 설명

소개 사이트 저장소에서 “메인 페이지와 스타일 파일의 역할, 로컬 확인 방법을 정리해 달라”고 요청합니다. 설명에 나온 경로가 실제 파일과 맞는지 확인한 뒤 작은 문구 수정으로 진행합니다.

시작 전에 정할 세 가지

  • 사용 화면과 실행 위치를 구분했는가
  • 저장소 경로와 현재 변경을 확인했는가
  • 첫 결과를 실제 파일과 대조했는가
