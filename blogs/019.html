Codex 06. 저장소에 AGENTS.md 남기기

솔루션 비제트 · OpenAI 공식 문서 기반 가이드 · 2026.10.19

저장소마다 테스트 명령과 파일 배치가 다릅니다. AGENTS.md에는 새로 온 작업자가 알아야 할 그 차이를 적어 두면 됩니다. 현재 저장소에서 실행해 본 명령과 편집할 경로부터 써 보세요.

어느 지침이 적용되나

Codex는 전역 지침과 프로젝트 경로의 지침을 조합해 읽을 수 있습니다. 디렉터리별 추가 지침과 override 파일이 있다면 적용 범위를 확인하세요. 파일 하나가 모든 하위 작업에서 같은 방식으로 적용된다고 추측하지 말고, 실제 읽은 지침의 출처를 확인해 두세요.

이 저장소에서 쓰는 규칙

설치 방법, 검사 명령, 생성 파일 위치, 변경 시 주의할 인터페이스처럼 지속적으로 필요한 내용을 씁니다. 존재하지 않는 테스트 명령이나 더 이상 쓰지 않는 배포 절차는 제거하세요. 비밀 키와 개인 계정 정보는 지침에 넣지 않습니다.

# 저장소 작업 안내 예시
- 페이지 수정 뒤 해당 화면과 내부 링크를 확인한다.
- 자동 생성 파일은 원본 생성 경로에서 수정한다.
- 완료 보고에 변경 파일과 실행한 검사를 적는다.

지침 파일이 권한 설정은 아니다

AGENTS.md는 작업 안내이며 파일 접근이나 네트워크 권한을 기술적으로 차단하는 장치는 아닙니다. 허용 범위는 별도의 권한·샌드박스 설정에서 확인하세요. 지침의 크기 제한과 탐색 규칙도 있으므로 장문의 자료는 참고 문서로 분리하는 편이 관리하기 수월합니다.

수정한 규칙은 새 작업에서 실제로 이해됐는지 확인합니다. 규칙이 적용되지 않으면 파일명, 현재 폴더, 추가 지침과의 관계를 살펴보세요. 모든 프로젝트에 필요 없는 제약을 전역 파일에 넣지 않는 것이 좋습니다.

정적 사이트라면 “페이지 경로를 바꾸면 내부 링크도 검사한다”처럼 실제 작업에 연결되는 규칙을 적을 수 있습니다. 검사에 쓰는 명령이 있다면 그 명령까지 함께 남겨 두세요.
