Claude 10. Windows에 Claude Code 설치하기

솔루션 비제트 · Anthropic 공식 문서 참고 가이드 · 2026.10.28

Claude Code를 설치하면 터미널에서 프로젝트 파일을 읽고 수정하는 작업을 맡길 수 있습니다. 먼저 작업할 폴더를 하나 정하고, 설치가 끝난 뒤 그 폴더에서 실행해 보세요. 버전 확인과 로그인이 되면 작은 문구 수정으로 동작을 시험할 수 있습니다.

Windows에서는 설치 경로 하나를 고른다

공식 문서는 네이티브 설치 프로그램, WinGet 등 여러 경로를 안내합니다. 여기서는 WinGet을 쓸 수 있는 Windows에서의 예를 들겠습니다. 이미 다른 방식으로 설치했다면 새로 겹쳐 설치하기 전에 현재 실행 경로와 설치 방식을 살펴보세요.

winget install Anthropic.ClaudeCode

설치가 끝나면 새 터미널을 열어 버전이 출력되는지 봅니다. 아래 명령은 설치 상태와 실행 파일 위치를 알아보는 용도입니다. 버전 번호가 나온다면 실행 파일은 찾은 상태이며, 계정 로그인과 첫 요청은 그다음 단계입니다.

claude --version
Get-Command claude

폴더를 연 다음 로그인한다

파일 탐색기나 터미널에서 연습 프로젝트 위치를 확인하고 그 폴더로 이동한 뒤 claude를 실행합니다. 화면의 로그인 안내에서 사용할 계정과 이용 경로를 선택하세요. 개인 구독과 API 계정은 사용량과 청구 방식이 다를 수 있으므로 이미 가지고 있는 로그인이라는 이유만으로 아무 항목이나 고르지 않습니다.

이 폴더의 파일 역할과 실행 방법을 설명해 줘.
아직 파일은 수정하지 말아 줘.
설명한 내용의 근거가 되는 파일 경로를 함께 적어 줘.

응답에 나온 파일이 실제 폴더에 있는지 보고, 테스트 명령이 있다면 프로젝트에서 쓰는 명령과 맞는지 읽습니다. 구조 설명이 맞은 뒤 오탈자 한 곳 정도의 변경으로 넘어가면 됩니다.

실행되지 않을 때 다시 설치하기 전에

명령을 찾지 못하면 새 터미널에서도 같은지, 설치 경로가 PATH에 들어 있는지부터 살펴봅니다. 버전은 나오는데 로그인에 실패하면 설치보다 인증이나 네트워크 쪽 문제일 수 있습니다. 오류 문구를 남기되 인증 코드나 키는 공개하지 마세요.

명령을 찾을 수 없다는 메시지가 나오면 새 터미널에서 버전을 확인해 보세요. 계속 실패한다면 설치 방식과 오류 문구를 함께 기록합니다. 같은 설치 명령을 반복하기 전에 어느 단계까지 됐는지 알아두면 원인을 좁힐 수 있습니다.
