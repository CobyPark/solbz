낯익은 이름으로 온 메일도 주소 보기

솔루션 비제트 · 보안 인식 노트

거래처 이름이 표시된 메일이라도 송금 계좌를 바꾸라는 내용이면 따로 확인할 필요가 있습니다. 발신 주소와 링크를 읽고, 평소 쓰던 연락처로 담당자에게 물어보세요. 메일에 새로 적힌 연락처만으로 확인하면 같은 사람에게 다시 묻게 될 수 있습니다.

표시 이름과 실제 발신 주소

메일의 표시 이름은 발신자가 정할 수 있습니다. 주소를 펼쳐 평소 주고받던 도메인과 비교해 보세요. 주소가 같아 보여도 계정이 탈취됐을 수 있으므로 중요한 요청은 내용과 전달 경로도 살펴야 합니다.

평소보다 급한 요청

계정 정지나 당일 송금을 강조하는 메일은 바로 처리하기 전에 담당자에게 물어보세요. 예전에 저장한 전화번호처럼 따로 확보한 연락처를 사용합니다. 메일에 회신하는 것만으로 확인을 마치면 같은 발신자에게 다시 묻게 될 수 있습니다.

표시 문구와 실제 링크

링크 위에 마우스를 올려 실제 주소를 읽거나 링크 주소를 확인할 수 있습니다. 로그인해야 한다면 평소 쓰던 공식 주소로 직접 들어가는 방법도 있습니다. 익숙한 로고와 디자인만으로 로그인 화면을 판단하기 어렵습니다.

첨부파일 확장자

탐색기에서 확장자를 보이게 해 실제 파일 형식을 읽어 보세요. 문서 이름 뒤에 .exe 같은 실행 형식이 붙을 수 있습니다. 평소 주고받지 않던 첨부파일은 발신자에게 별도 연락으로 확인하고, 매크로나 보안 기능 해제를 요구하면 조직의 처리 절차를 따릅니다.

의심되는 링크를 눌렀다면 어떤 주소가 열렸고 정보를 입력했는지 기록해 담당자에게 알려 주세요. 비밀번호를 입력했다면 해당 서비스의 공식 주소에서 변경하고 로그인 기록을 살펴봅니다. 메일 원문도 조사할 수 있도록 남겨 둡니다.
