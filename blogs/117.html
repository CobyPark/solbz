크롬 확장 프로그램의 권한 읽기

솔루션 비제트 · 브라우저 보안 노트

메모 도구가 모든 사이트의 데이터를 읽겠다고 하면 어떤 기능에 필요한지 알아볼 만합니다. 확장 프로그램을 설치할 때는 설명과 함께 권한 목록, 개발자, 최근 업데이트를 읽어 보세요. 이미 설치한 확장도 가끔 정리할 필요가 있습니다.

기능에 필요한 권한인지

설치 화면의 권한 목록을 보고 기능 설명과 연결해 보세요. 페이지 내용을 저장하는 도구라면 페이지 접근 권한이 필요할 수 있습니다. 접근 대상을 특정 사이트로 제한할 수 있는지도 브라우저 설정에서 살펴봅니다.

개발자와 업데이트 이력

스토어의 개발자 정보와 공식 사이트를 읽고 최근 변경 내용을 살펴보세요. 업데이트가 있다는 사실만으로 안전성을 판단할 수는 없지만, 추가 기능과 권한이 바뀐 이유를 알아보는 데 도움이 됩니다.

쓰지 않는 확장 정리

필요 없는 확장은 제거하고, 문제를 찾는 중이라면 하나씩 사용 중지해 비교해 볼 수 있습니다. 확장이 사라진 뒤에도 외부 서비스에 연결한 계정 권한이 남아 있다면 그 서비스에서 별도로 해제합니다.

업무용 프로필 분리

업무용 브라우저에서는 조직이 허용한 확장을 기준으로 사용하세요. 새 확장을 시험할 때는 별도 프로필을 쓰면 현재 작업에 미치는 영향을 줄일 수 있습니다. 프로필을 나눠도 설치한 확장의 권한 자체는 읽어 보아야 합니다.

확장을 하나씩 꺼 보면 사이트 오류나 느려짐의 원인을 찾는 데도 도움이 됩니다. 쓰지 않는 확장은 제거하고 필요한 것만 남겨 두세요. 권한이 바뀌는 업데이트가 있다면 추가한 기능과 권한이 맞는지 다시 읽어 봅니다.
