윈도우 11 공유폴더의 접근 권한 살펴보기

솔루션 비제트 · IT 인프라 노트

공유폴더가 열린다고 해서 권한 설정까지 끝난 것은 아닙니다. 같은 네트워크의 누가 자료를 읽고 바꿀 수 있는지 살펴봐야 합니다. Windows의 네트워크 프로필과 공유 권한, NTFS 권한이 각각 어디에 영향을 주는지부터 짚어 봅니다.

신뢰하는 네트워크에서만 공유

Windows 설정에서 현재 네트워크 프로필을 확인하세요. 사내에서 관리하는 네트워크라면 개인 프로필에서 필요한 공유 기능을 사용할 수 있습니다. 외부 와이파이에 연결했을 때도 같은 공유 설정이 적용되는지 따로 살펴봐야 합니다.

SMBv1 사용 여부

오래된 장비와 연결하려고 SMBv1을 켠 적이 있다면 지금도 필요한지 확인해 보세요. 구형 프로토콜을 계속 써야 하는 장비는 지원되는 연결 방식으로 바꿀 수 있는지 검토합니다. Windows 기능의 SMB 1.0/CIFS 항목에서 설치 상태를 볼 수 있습니다.

계정별 공유 권한과 NTFS 권한

네트워크 공유로 접근할 때는 공유 권한과 NTFS 권한이 함께 영향을 줍니다. 읽기만 필요한 계정으로 파일을 수정할 수 없는지, 담당 계정은 필요한 폴더를 열 수 있는지 각각 시험해 보세요. Everyone에 넓은 권한을 주었다면 실제 필요한 계정이나 그룹으로 범위를 줄일 수 있습니다.

접근 로그와 남은 권한

접근 이력을 남기려면 관련 감사 설정이 준비돼 있어야 합니다. 필요한 파일 작업이 기록되는지 시험하고 보관 기간을 정하세요. 담당자 변경이나 퇴사 때는 계정과 그룹에 남은 권한도 같이 정리합니다.

BZ SMB Settings를 쓰면 PC의 공유 관련 설정을 살펴보는 데 도움을 받을 수 있습니다. 적용 전에는 공유할 폴더와 사용 계정을 정해 두세요. 적용 후에는 허용한 계정에서 필요한 작업이 되는지 시험합니다.
