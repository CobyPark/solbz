ChatGPT 02. 질문 잘 쓰기: 목적·자료·출력 형식을 한 번에 전달하기

솔루션 비제트 · OpenAI 공식 문서 기반 가이드 · 2026.10.19

질문을 잘 쓰려고 전문 용어를 늘릴 필요는 없습니다. 누가 읽을 결과인지, 어떤 자료를 쓸지, 무엇을 만들면 끝나는지 알려주면 됩니다. 조건이 많다면 짧은 항목으로 나눠 서로 모순되는 지시가 없는지 읽어보세요.

독자와 사용 목적

보고서, 고객 안내문, 개인 학습 노트는 같은 자료라도 강조점이 다릅니다. 독자와 사용 목적을 먼저 적고 원하는 길이나 언어를 덧붙입니다. 자신이 중요하게 생각하는 용어가 있다면 짧게 정의하세요.

참고 자료는 별도 구역에

원문은 별도 구역으로 넣고 그 밖의 정보를 찾아도 되는지 정합니다. 첨부 파일이 여러 개라면 어떤 자료를 우선할지와 버전 차이를 설명하세요. 입력에 없는 값을 추정해도 되는지, 확인 필요로 남겨야 하는지도 알려줍니다.

목적: 내부 검토용 한 쪽 메모
자료: 첨부한 가상 비교표만 사용
구조: 차이점 / 선택 조건 / 확인할 질문
규칙: 근거 없는 성능·가격은 추가하지 않기

원하는 형식과 우선순위

“깔끔하게”보다 표의 열 이름이나 문단 순서가 구체적입니다. 설명이 필요한 이유까지 알려주면 후속 수정이 줄어들 수 있습니다. 다만 조건을 지나치게 늘려 서로 모순되지 않도록 우선순위를 정하세요.

응답을 본 뒤 빠진 정보는 해당 항목에 보탭니다. 먼저 잘못된 사실을 고치고 다음에 말투와 분량을 다듬는 편이 결과를 확인하기 수월합니다. 같은 요청 틀을 저장해 반복 업무에 맞게 바꿔 사용할 수 있습니다.

비교 자료로 요청서 써 보기

장비 A·B 비교 자료로 요청서를 만듭니다. 답변의 각 차이점이 입력 표의 어느 행에 근거하는지 확인하고, 자료에 없는 가격이나 수치가 추가되면 해당 조건을 다시 명시합니다.

요청에 빠진 것은 없나

  • 독자와 목적을 설명했는가
  • 자료 범위와 추정 허용 여부가 분명한가
  • 출력 형식과 확인 기준이 있는가
