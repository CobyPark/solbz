목록으로 돌아가기 PC 관리

PC가 느려졌을 때 작업 관리자부터 보기

솔루션 비제트 · 컴퓨터 활용 노트

PC가 버벅거리면 작업 관리자에서 CPU, 메모리, 디스크 사용량을 살펴보세요. 느려진 순간에 어떤 프로그램이 자원을 쓰는지 볼 수 있습니다. 부팅 직후만 느린지, 특정 작업에서 계속 느린지도 구별해 둡니다.

시작 프로그램

부팅 직후에만 느리다면 작업 관리자의 시작 앱을 살펴보세요. 어떤 프로그램인지 알아본 뒤 지금 필요 없는 항목부터 자동 실행을 끌 수 있습니다. 보안 프로그램이나 장치 관리 항목은 역할을 확인하고 변경합니다.

디스크 여유 공간

시스템 드라이브에 임시 파일과 업데이트를 저장할 공간이 남아 있는지 보세요. 필요한 여유 공간은 작업과 드라이브에 따라 다릅니다. 저장소 설정에서 큰 항목을 찾고, 옮길 자료는 새 위치에서 열리는지 확인한 뒤 정리합니다.

백그라운드 앱과 동기화

대용량 파일을 올리는 동기화 작업이나 업데이트가 디스크를 계속 사용할 수 있습니다. 작업 관리자에서 사용량이 높은 프로그램과 현재 작업을 비교해 보세요. 일시 중지해도 되는 작업이라면 멈춘 뒤 같은 증상이 나는지 시험합니다.

드라이버와 업데이트

새 드라이버를 설치한 뒤 느려졌는지, 오랫동안 업데이트하지 않았는지부터 구별해 보세요. 장치 제조사가 제공하는 해당 모델용 드라이버를 기준으로 변경 이력을 봅니다. 업데이트 전에는 복구 방법과 중요한 자료의 백업을 준비합니다.

악성코드 검사

원인을 알 수 없는 프로그램이 계속 실행되거나 CPU와 네트워크 사용량이 높다면 보안 검사를 해 볼 수 있습니다. Windows 보안 등 사용하는 보안 프로그램의 검사 결과를 읽어 보세요. 높은 사용량만으로 감염을 단정할 수는 없으므로 프로세스와 작업 시점도 함께 남깁니다.

느려지는 시점과 사용량을 기록하면 다음 조치를 정하기 쉽습니다. 프로그램 하나를 종료한 뒤 같은 작업을 다시 해 보세요. 디스크 오류나 과열 같은 징후가 있다면 중요한 자료부터 백업하고 원인을 점검합니다.
