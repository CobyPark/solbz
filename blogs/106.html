IT 솔루션 계약 전에 물어볼 질문

솔루션 비제트 · IT 컨설팅 노트

시연에서 잘 보이던 기능도 회사의 실제 파일과 계정으로 쓰면 다르게 동작할 수 있습니다. 계약 전에는 평소 처리하는 자료 한 세트로 업무를 해 볼 수 있는지 물어보세요. 지원 범위와 자료를 돌려받는 방법도 이때 정할 내용입니다.

요구사항과 완료 기준

지금 처리하는 순서와 불편한 지점을 적고, 도입 후 수행할 작업을 예로 보여 주세요. “월별 매출 CSV를 올리면 거래처별 합계가 나온다” 정도로 구체적이면 시연에서도 같은 작업을 해 볼 수 있습니다.

기존 데이터와의 연동

기존 시스템에서 어떤 파일이나 API를 제공하는지 알아보세요. 공급업체가 읽을 수 있는 형식과 갱신 주기, 오류가 났을 때 고칠 담당자까지 정해야 합니다. 연동이 안 되는 항목은 누가 수동으로 입력할지도 남겨 둡니다.

보안 기준과 데이터 보관

저장되는 데이터의 종류와 위치, 접근 권한을 문서로 받아 두세요. 개인정보가 있다면 조직의 처리 기준과 계약 조건도 대조해야 합니다. 계약 종료 후 삭제와 반환을 어떻게 확인할지도 물어볼 수 있습니다.

유지보수와 응답 시간

장애 연락처와 접수 가능한 시간을 확인하세요. 접수에 답하는 시간과 복구를 목표로 하는 시간은 계약에서 각각 어떻게 정하는지 읽어 봅니다. 데이터 복구나 기능 수정이 추가 비용인지도 함께 물어보세요.

도입 후 비용까지 계산

사용 예정 기간을 정하고 라이선스, 교육, 연동 개발, 유지보수 비용을 합쳐 보세요. 사용자 수나 저장량이 늘면 달라지는 금액도 넣습니다. 비교한 기간과 사용량을 견적표 옆에 적어 두면 조건이 바뀌었을 때 다시 계산하기 쉽습니다.

견적서에 없는 비용과 조건은 질문 목록으로 보내 답변을 받아 두세요. 장애 대응 시간, 추가 사용자 비용, 계약 종료 시 자료 형식처럼 운영하면서 필요한 항목입니다. 구두 설명과 계약 문구가 같은지도 읽어 봅니다.
