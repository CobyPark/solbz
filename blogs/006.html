Claude 06. Artifacts로 납품비 계산기 만들기

솔루션 비제트 · Anthropic 공식 문서 참고 가이드 · 2026.10.28

배송비를 설명할 때마다 계산식을 풀어 쓰고 있다면 입력칸이 있는 작은 계산 화면을 만들어 볼 만합니다. Artifacts에는 “거리와 수량을 넣으면 납품비가 나오는 화면”처럼 용도와 계산 규칙을 함께 알려 주세요.

납품비 계산기로 범위를 줄여 보기

연습 주제는 수량과 단가, 배송비를 넣으면 합계를 보여 주는 계산기입니다. 실제 견적서가 아니라 계산 흐름을 확인하는 예제이므로 세금, 할인, 환율은 이번 범위에서 빼겠습니다. 화면을 그리기 전에 계산식을 먼저 정해 두면 수정할 때 기준이 생깁니다.

수량, 단가, 배송비를 입력하는 계산 화면을 Artifact로 만들어 줘.
합계 = 수량 × 단가 + 배송비로 계산하고 원 단위로 표시해 줘.
빈 입력과 음수는 합계를 내지 말고 안내를 보여 줘.
회원 가입, 결제, 외부 서버 연결, 데이터 저장은 넣지 말아 줘.
휴대전화에서도 입력칸과 결과가 잘리지 않게 배치해 줘.

공식 안내에 따르면 Artifacts를 쓰려면 파일 생성·편집에 해당하는 기능이 켜져 있어야 합니다. 결과가 일반 채팅 답변으로만 나오면 계정의 기능 설정과 현재 지원 범위를 살펴보세요. 템플릿과 공유 기능은 결과 종류와 요금제에 따라 다를 수 있습니다.

그럴듯한 화면과 맞는 계산은 따로 본다

수량 3, 단가 12,000원, 배송비 3,000원을 넣었다면 합계는 39,000원입니다. 이 값을 먼저 대조한 뒤 입력을 비우거나 수량을 음수로 바꿔 봅니다. 안내가 뜬 상태에서 직전 합계가 그대로 남아 오해를 주지 않는지도 살펴볼 수 있습니다.

금액에 쉼표를 넣었을 때, 배송비를 0으로 입력했을 때, 화면 폭을 줄였을 때도 확인합니다. 잘못된 값이 나오면 “계산이 틀린다” 대신 입력한 값과 기대한 합계를 알려 주세요. 색상 수정과 계산 오류 수정을 한꺼번에 맡기지 않으면 바뀐 이유를 따라가기 쉽습니다.

링크를 보내기 전에 담긴 내용을 읽는다

공유할 수 있는 결과라도 바로 공개할 필요는 없습니다. 연습용 수치 대신 고객 단가나 내부 조건을 넣었다면 먼저 지우고 공유 설정을 읽습니다. 링크가 열리는지와 받는 사람이 보게 되는 내용은 별도 창이나 허용된 다른 계정에서 점검할 수 있습니다.

공유 링크를 보내기 전에는 수량 0, 경계 금액, 아주 큰 입력값을 넣어 보세요. 평소 입력에서 잘 맞는 계산도 경계에서 틀릴 수 있습니다. 직접 계산한 몇 가지 값과 나란히 놓고 보면 오류를 찾기 쉽습니다.

공식 참고: Artifacts 사용 안내. 문서 확인: 2026.10.28.
